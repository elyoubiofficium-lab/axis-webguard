WHAT IT DOES

Useful signals.
Clear explanations.

WebGuard reviews selected page and link characteristics and explains why something may deserve a closer look.

⌕

Link review

Highlights selected link patterns, including insecure HTTP links and unusual destinations.

◎

Domain warning signs

Checks for selected suspicious domain patterns and lookalike naming signals.

▤

Form awareness

Reviews page forms for characteristics that may deserve attention, such as insecure submission.

↗

Connection checks

Shows whether the current page uses HTTPS and explains what encryption does and does not mean.

✧

Readable findings

Turns technical signals into simple warnings and practical explanations.

⌂

Local-first approach

The current version performs its checks locally in the browser without sending page data to an AXIS server.

HOW IT WORKS

Three simple steps.

No complicated setup. Review the page you are already visiting.

STEP 01

Open a website

Visit the page you want to review in Google Chrome.

STEP 02

Run a scan

Open the AXIS WebGuard extension and choose the scan action.

STEP 03

Review the findings

Read the signals and explanations before deciding what to do next.

♢

Privacy matters.

The current version is designed to run its checks locally in Chrome. It does not send the page content to an AXIS scanning server. The extension only requests access to the active tab when you use it.
